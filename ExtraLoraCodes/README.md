## 📌 Overview

Lora Hub is a modular userscript-based control system that injects a floating UI panel into any webpage.  
It enables real-time interface customization and visual experimentation through:

- Theme switching
- CSS visual effects
- UI scaling tools
- Gradient text generation
- Page utility controls

Designed for frontend experimentation and UI/UX prototyping.

---

## ✨ Features

### 🎨 Theme Engine
- 100+ dynamic visual presets
- CSS filter-based rendering system
- Instant apply/reset functionality
- Lightweight performance design

### ⚡ Effects System
- Blur, contrast, grayscale, invert
- Screen shake simulation
- Hue rotation modes
- Glitch-style transformations
- Flash inversion effects

### 🌈 Gradient Engine
- Multi-color gradient text generation
- Live DOM injection
- Custom input rendering support

### 🧪 Utility Tools
- Zoom in/out/reset controls
- Font scaling tools
- Page title editing
- Clipboard URL copy tool
- Debug utilities

## 🚀 Installation

### 1. Install Tampermonkey
https://www.tampermonkey.net/

### 2. Create a New Script
- Open Tampermonkey Dashboard
- Click "Create New Script"

### 3. Paste Script
Paste the full Lora Hub userscript code

### 4. Save & Enable
Enable the script and refresh any webpage
